# Frequently Asked Questions (FAQ)

This page answers common questions about the Unit 3 EL-12 project.

## 1. What is this project?

This project demonstrates how to create and organize documentation using Markdown files in GitHub.

## 2. What is Markdown?

Markdown is a lightweight markup language used to format text using headings, lists, links, and other elements.

## 3. What is the purpose of the docs folder?

The `docs/` folder stores documentation files separately from the other files in the repository.

## 4. How do I view the documentation?

Open the `docs/` folder in the repository and select the required Markdown file.

## 5. How do I write a heading in Markdown?

Use the `#` symbol before the heading text.

Example:

```markdown
# Main Heading
## Subheading
### Smaller Heading
```

## 6. How do I create a list?

Use hyphens to create a bulleted list.

Example:

```markdown
- First item
- Second item
- Third item
```
